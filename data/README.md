# Data

This folder contains the climate, satellite, and field-observation datasets used to investigate microclimatic variations across Jahangirnagar University campus.

### Data sources
- **ERA5:** Air temperature data (2011–2025) for temporal and seasonal analysis.
- **MODIS:** 8-day composite Land Surface Temperature (LST) data (2011–2025).
- **Landsat 8:** Satellite imagery used for Land Use and Land Cover (LULC) classification and NDVI analysis.
- **Field observations:** On-site air temperature measurements collected during December and February.
