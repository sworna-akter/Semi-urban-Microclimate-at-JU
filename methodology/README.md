# Methodology

This folder documents the methods used to examine spatial and temporal microclimatic variations across Jahangirnagar University campus.

### Main analytical approaches

1. **Climate data analysis:** ERA5 daily temperature data were summarised into monthly and seasonal statistics using descriptive statistical methods.
2. **Land Surface Temperature:** MODIS 8-day LST data were analysed for spatial distribution and temporal trends using linear regression, the Mann–Kendall test, and Sen's slope estimator.
3. **LULC and NDVI analysis:** Landsat 8 imagery was used to prepare land use and land cover and vegetation index maps.
4. **GIS-based zoning:** Temperature, LST, LULC, and NDVI layers were integrated in ArcGIS to identify four microclimatic zones.
5. **Field validation:** On-site temperature observations from December and February were compared with web-based temperature data across different land-cover categories.

The analysis combines remote sensing, GIS, statistical techniques, and field observations to understand campus-level microclimatic variability.
